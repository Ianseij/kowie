# KOWIE — 001

A minimalist, gender-neutral website for KOWIE.

## Free GitHub Pages setup

1. Create a GitHub account at https://github.com/
2. Create a new **public** repository named `kowie`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. Your free site will be available at:
   `https://YOUR-USERNAME.github.io/kowie/`

No paid domain is required.
